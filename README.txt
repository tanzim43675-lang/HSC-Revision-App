HSC Revision Android application source.
Build an APK with Android Studio:
1. Open this folder in Android Studio.
2. Allow Gradle sync and SDK installation.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Copy app/build/outputs/apk/debug/app-debug.apk to the Android phone and install.
This archive is a buildable Android project, NOT an already-built APK.
The app stores progress in Android WebView localStorage; uninstalling may delete data. Export a backup first.
